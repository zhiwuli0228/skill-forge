# Operations Documentation

This directory contains installation, runtime, maintenance, security, and troubleshooting guidance.

## Purpose

Use this directory for operational guidance needed to run Skill Forge safely and repeatedly in local or team environments.

## What Belongs Here

- Installation guide
- Runtime usage notes
- Security and compliance guidance
- Troubleshooting
- Maintenance procedures
- Backup or migration notes
- Operational checklists

## Recommended Files

- `install-and-runtime.md`
- `security-compliance.md`
- `troubleshooting.md`
- `maintenance.md`
- `operational-checklist.md`

## What Does Not Belong Here

- Product roadmap
- Architecture design
- OpenSpec change proposals
- AI Harness rules
- Domain behavior definitions

## Current Rule

Operational docs must distinguish safe read-only commands from commands that mutate files, workspace state, or user configuration.
