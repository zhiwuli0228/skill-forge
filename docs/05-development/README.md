# Development Documentation

This directory contains local development and engineering workflow guidance.

## Purpose

Use this directory to help developers and agents run, test, validate, package, and release Skill Forge consistently.

## What Belongs Here

- Local setup instructions
- Common development commands
- Test strategy
- Dependency policy
- Release policy
- Versioning rules
- Developer troubleshooting

## Recommended Files

- `local-development.md`
- `testing-guide.md`
- `dependency-policy.md`
- `release-policy.md`
- `command-reference.md`
- `troubleshooting-dev.md`

## What Does Not Belong Here

- Architecture decisions
- OpenSpec change artifacts
- AI Harness rules
- Superpowers execution discipline
- Historical taskbooks

## Current Rule

Development docs should prefer exact commands over prose. Any command that modifies the repository must state its expected file impact.
