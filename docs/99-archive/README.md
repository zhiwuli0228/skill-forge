# Archive

This directory stores historical, superseded, or process-only documents.

## Purpose

Use this directory to preserve traceability without polluting the current documentation authority.

## What Belongs Here

- Old design drafts
- Superseded planning documents
- One-off taskbooks
- Obsolete reports
- Historical phase notes
- Documents kept only for audit or reference

## What Does Not Belong Here

- Current architecture authority
- Current AI Harness rules
- Active OpenSpec workflow guidance
- Current development commands
- Current domain behavior rules

## Archive Rules

1. Moving a document into this directory must be done through a separate cleanup change.
2. Archived documents are not current authority.
3. If an archived document is still relevant, create or update a current document that references it explicitly.
4. Do not delete archived documents unless the user explicitly approves deletion.

## Recommended Subdirectories

- `old-designs/`
- `taskbooks/`
- `reports/`
- `superseded-roadmaps/`
