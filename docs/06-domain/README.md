# Domain Documentation

This directory contains Skill Forge domain rules and product behavior definitions.

## Purpose

Use this directory to define the domain concepts that Skill Forge manages, such as skills, blueprints, validation, lifecycle recommendation, provenance, and platform adapters.

## What Belongs Here

- Skill authoring rules
- Skill package structure
- Blueprint rules
- Validation rules
- Lifecycle recommendation rules
- Provenance rules
- Platform adapter behavior
- Domain terminology

## Recommended Files

- `skill-authoring-domain.md`
- `skill-package-contract.md`
- `blueprint-rules.md`
- `validation-rules.md`
- `lifecycle-rules.md`
- `provenance-rules.md`
- `platform-adapter-rules.md`
- `domain-glossary.md`

## What Does Not Belong Here

- Local setup commands
- Generic coding standards
- OpenSpec artifact templates
- Phase reports
- Old design drafts

## Current Rule

Domain docs define expected Skill Forge behavior. If implementation and domain docs disagree, create a governed change instead of silently changing behavior.
